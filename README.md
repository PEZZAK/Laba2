# Старков Владимир ИТ-6 Лабораторная №2

Все задачи сделаны в одном проекте, но в разных классах: `Name`, `House`, `Employee`, `Department`, `Fraction`. В каждом классе есть поля, свойства, конструкторы и метод `ToString()`. Для проверки ввода с клавиатуры есть отдельный класс `Proverka`: если ввели не число, пустую строку или неподходящее число, программа пишет об ошибке и просит ввести ещё раз. Для имён есть отдельная проверка: в них могут быть только буквы и дефис (дефис не может стоять в начале или в конце), а пустую строку программа не принимает. Название отдела проверяется только на то, что оно не пустое. В `Main` по очереди показывается работа всех классов.

В `Main` создаём три имени из условия и выводим их. У Клеопатры есть только имя, поэтому выведется одно слово. У Маяковского нет отчества, и в строке его тоже нет.

Нужно два класса, которые ссылаются друг на друга. У сотрудника есть отдел, а у отдела есть начальник, который тоже сотрудник.

Класс `Employee` хранит имя и отдел. Класс `Department` хранит название, начальника и список сотрудников. У обоих классов есть свойства и конструкторы. Чтобы добавить сотрудника в отдел, в `Department` есть метод `AddEmployee`. Он добавляет сотрудника в список и сразу записывает ему ссылку на отдел.

Во всех остальных случаях выводим «Имя работает в отделе Название, начальник которого Имя начальника». Если начальник ещё не назначен, пишем «не назначен».

В `Main` создаём отдел IT и трёх сотрудников: Петрова, Козлова и Сидорова. Добавляем их в отдел, назначаем Козлова начальником и выводим всех троих.

# Задание 5

## Задача 5

### Текст задачи

Дроби. Создайте сущность Дробь со следующими особенностями:
- Имеет числитель: целое число.
- Имеет знаменатель: целое число.
- Дробь может быть создана с указанием числителя и знаменателя.
- Может вернуть строковое представление вида «числитель/знаменатель».
- Может выполнять операции сложения, вычитания, умножения и деления с другой Дробью или целым числом. Результатом операции должна быть новая Дробь (таким образом, обе исходные дроби не изменяются).

Затем необходимо выполнить следующие задачи:
1. Создать несколько экземпляров дробей.
2. Написать по одному примеру использования каждого метода.
3. Вывести на экран примеры и результаты их выполнения в формате «1/3 * 2/3 = 2/9».
4. Посчитать f1.sum(f2).div(f3).minus(5).

### Алгоритм решения

Класс `Fraction` хранит числитель и знаменатель. К ним сделаны свойства, но только для чтения (без `set`), поэтому после создания дробь поменять нельзя. Это нужно, чтобы операции возвращали новые дроби, а старые не менялись.

Вся работа происходит в конструкторе. Сначала он проверяет знаменатель: если он равен 0, программа выдаёт ошибку «Знаменатель не может быть нулём». Потом делаем так, чтобы знак минус всегда стоял в числителе: если знаменатель отрицательный, меняем знак и у числителя, и у знаменателя (например, 1/-3 превращается в -1/3). После этого дробь сокращается. Для этого находим наибольший общий делитель (НОД) числителя и знаменателя и делим на него обе части. НОД ищем по алгоритму Евклида: пока второе число не равно 0, заменяем пару (a, b) на (b, остаток от деления a на b). Когда второе число стало 0, первое и есть НОД. Например, для дроби -3/9 берём числа 3 и 9: (3, 9) → (9, 3) → (3, 0), НОД равен 3, и получается -1/3.

Для каждой операции сделано два метода: один принимает другую дробь, второй принимает целое число. Каждый метод создаёт и возвращает новую дробь, а старые не меняются. Вот как считаются операции:
- Сложение: приводим дроби к общему знаменателю. Новый числитель равен «числитель первой × знаменатель второй + числитель второй × знаменатель первой». Новый знаменатель равен произведению знаменателей.
- Вычитание: так же, как сложение, только вместо плюса минус.
- Умножение: числитель умножаем на числитель, знаменатель на знаменатель.
- Деление: делим, умножая на «перевёрнутую» дробь. Новый числитель равен «числитель первой × знаменатель второй», новый знаменатель равен «знаменатель первой × числитель второй». Если числитель второй дроби равен 0, делить нельзя, и метод выдаёт ошибку.
- Операции с целым числом: целое число можно представить как дробь со знаменателем 1. При сложении к числителю прибавляем «число × знаменатель», при вычитании отнимаем столько же. При умножении умножаем числитель на число. При делении умножаем знаменатель на число (если число 0, выдаём ошибку).

Результат каждой операции отправляется в конструктор, поэтому он автоматически сокращается и знак остаётся в числителе.

Метод `ToString()` возвращает строку вида «числитель/знаменатель».

В `Main` создаём три дроби: f1 = 1/3, f2 = 2/3 и f3 = 1/2, и выводим их. Потом показываем по одному примеру каждого метода: сначала четыре операции с другой дробью (сложение, вычитание, умножение, деление), потом четыре операции с целым числом. Каждый пример выводится в формате «1/3 * 2/3 = 2/9». Потом ещё раз выводим f1, f2 и f3, чтобы показать, что исходные дроби после операций не изменились. В конце считаем выражение из условия: `f1.Sum(f2).Divide(f3).Minus(5)`. Методы можно вызывать цепочкой, потому что каждый возвращает новую дробь. Считаем по шагам: 1/3 + 2/3 = 1/1, потом 1/1 делим на 1/2 и получаем 2/1, потом вычитаем 5 и получаем -3/1.

### Тестирование

Ожидаемый результат:
```
Исходные дроби:
f1 = 1/3
f2 = 2/3
f3 = 1/2

Операции с другой дробью:
1/3 + 2/3 = 1/1
1/3 - 2/3 = -1/3
1/3 * 2/3 = 2/9
1/3 / 1/2 = 2/3

Операции с целым числом:
1/3 + 1 = 4/3
1/3 - 1 = -2/3
1/3 * 2 = 2/3
1/3 / 2 = 1/6
```
